# TgChanel — автопостинг ідіом

Telegram-бот, який сам веде канал про англійські ідіоми та колокації:
Gemini вигадує фразу й живе пояснення українською, GIPHY підбирає
реакцію-гіфку за настроєм фрази, і все це приходить адміну на ревʼю —
у канал нічого не публікується без ручного схвалення.

Уся документація — запуск, ключі, команди бота, усунення несправностей,
перенесення на інший ПК — в **[docs/RUNBOOK.md](docs/RUNBOOK.md)**.

```bash
docker compose up -d --build
```
